# Dezembro Vermelho — site educativo

Site responsivo em HTML/CSS/JS puro, pronto para GitHub Pages.

## Como usar
1. Extraia o ZIP.
2. Envie `index.html` para um repositório do GitHub.
3. Em Settings > Pages, selecione a branch/pasta usada pelo projeto.
4. O site funciona sem servidor ou Firebase.

## Conteúdo
- Hero moderno e minimalista
- Seções sobre a campanha
- Prevenção combinada
- PEP e PrEP
- Tratamento e I=I
- Linha do tempo
- FAQ interativo
- Menu mobile
- Animações de entrada
- Fontes oficiais do Ministério da Saúde/BVS
